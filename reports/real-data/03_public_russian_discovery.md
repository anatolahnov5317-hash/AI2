## Выполненный технический smoke

`python scripts/public_russian_discovery_smoke.py` считывает **из закреплённого
Git commit**, а не из изменяемых файлов рабочего каталога, три русских
документа проекта:

1. `docs/ALGORITHM.md` — описание собственного алгоритма.
2. `docs/OPEN_OBSERVATIONS.md` — описание импорта наблюдений.
3. `docs/real_data/P02_CORPUS_INTEGRITY.md` — инструкция корпуса.

В этих трёх файлах не обнаружены адреса почты, прямые ссылки на сторонний
контент или явные персональные сведения; это ограниченная ручная проверка, а
не юридическое заключение. Точные SHA-256 байтов закреплены в скрипте.
Скрипт создаёт только временную SQLite-базу, дважды импортирует каждый файл,
сверяет исходные байты, Unicode и UTF-8 координаты каждого фрагмента,
SHA-256 и неизменность версии `1`. Все три документа консервативно получают
**одно** родственное семейство; `annotation_coverage` остаётся `unknown`.
Он не создаёт gold, не назначает splits и не читает sealed_test.

Результат: **3/3** документа импортированы, SHA-256 и координаты совпали,
повторный импорт не создал новую ревизию. Совокупный размер 31 224 байта:
`7 329 + 13 875 + 10 020`.

## Границы следующего шага

- Открытые AI2 docs годятся для отладки P02 без тестирования качества модели;
  Issue не использовать как лицензированный русский журнал задач без
  отдельного подтверждения прав и разметки переходов.
- [NEREL](https://github.com/nerel-ds/NEREL) и
  [RuCoCo](https://github.com/vdobrovolskii/rucoco) могут дать отдельную
  русскую диагностику упоминаний/кореференции, если подтверждены права на
  соответствующие тексты. Они не содержат историю задач одного проекта и
  не заменяют P01/P05. [CorefUD 1.4](https://ufal.mff.cuni.cz/corefud)
  распространяет корпуса на различных условиях; их проверяют по отдельности.
- До фиксации настоящих `train`, `development`, `calibration` владелец
  процесса подтверждает права на документы и task log, происхождение меток,
  границы связанных семейств и инвентарь групп. Затем распределяются **целые
  семейства**, а не окна или версии. Будущий `sealed_test` отдельный хранитель
  назначает и закрывает до выбора порогов; в этой разведке он не отбирался.

Для повторения подсчётов на указанном Git-срезе:

```bash
git ls-files docs README.md | wc -l
git ls-files 'docs/**/*.md' 'docs/*.md' README.md | wc -l
git log --all --format=%H -- docs | wc -l
python scripts/public_russian_discovery_smoke.py
```
