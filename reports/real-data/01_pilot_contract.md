# P01: паспорт пилота и протокол оценки

Статус: контракт технически проверен как **черновик**. Приёмка P01 остаётся
открытой до подтверждения источников данных, прав, целевого оборудования,
цены ошибок и численных допусков блока 1 владельцем процесса. Обучение и
пилотные ответы этим PR не запускаются.

## Поставлено

- [`docs/real_data/pilot_contract.yaml`](../../docs/real_data/pilot_contract.yaml):
  машинно проверяемые область, источники, язык, baseline, независимая единица,
  splits и точные знаменатели пилотных метрик. Это JSON-совместимый YAML 1.2.
- [`docs/real_data/EVALUATION_PROTOCOL.md`](../../docs/real_data/EVALUATION_PROTOCOL.md):
  инструкция отбора групп, разметки вопросов, закрытой проверки и применения
  верхней 95% границы риска.
- `scripts/validate_pilot_contract.py` и пять тестов: отдельный выход 2 при
  попытке объявить незавершённый паспорт утверждённым, проверки утечки старого
  GUM, неверного знаменателя риска/покрытия и коррелированных испытаний.
- CI проверяет паспорт на Python 3.10, 3.11 и 3.12 до длинной регрессии.

## Что уже доказано и чего не доказано

Английский GUM-контроль с исходного commit
`9bbae264eced86e6be2cccb565ea5c4162fc1e16` имеет exact-span F1 0,4055
против 0,3124 у простого baseline. Автоматический выбор идентичности отключён,
полезное покрытие связей равно 0. Старые четыре test-документа раскрыты.
Русского проверенного корпуса и новой закрытой оценки в P01 пока нет.

Код основной модели не менялся. Валидатор проверяет полноту и согласованность
**заявленного** контракта; он не может удостоверить действительное право
обработки, независимость источников или качество ответов.

## Проверки

```bash
python -m unittest discover -s tests -p test_pilot_contract.py -v
python scripts/validate_pilot_contract.py docs/real_data/pilot_contract.yaml
python scripts/validate_pilot_contract.py docs/real_data/pilot_contract.yaml --require-finalized
```

Первые две команды должны проходить; последняя должна возвращать 2 до
закрытия незаполненных решений. Для P01 это ожидаемая блокировка, а не
исправляемая подгонкой формальной метрики ошибка.

Локальный результат: 5/5 целевых тестов пройдены; черновик валиден без ошибок,
21 конкретное решение остаётся открытым; требование финализации возвращает 2.
После публикации ветки полный CI проверяет формат, типы и регрессию на трёх
версиях Python.
