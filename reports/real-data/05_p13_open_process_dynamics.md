# P13: открытый инженерный контур прогноза изменений

Статус: **механизм реализован; русская проверка P13 не начата**. Основой был
`15d2768b56952c845c04c2472544bdaaa7538c0c`. В репозитории нет доступных
цепочек «датированное состояние → событие → наблюдаемый позднее исход» с
независимыми русскими группами и правами для данного пилота. Цифр качества на
реальных переходах этот отчёт не заявляет. Прежние V05/V6 случаи известны и
не используются как новая закрытая проверка.

## Проверяемый интерфейс

`src/text_factors/real_data/process_dynamics.py` принимает уже
структурированные `TransitionPrompt` с датой известного состояния, временем
отсечения признаков, известным событием, заранее установленным горизонтом и
точным `group_id`. Результат `TransitionOutcome` хранится отдельно. Перед
обучением обязателен явный список отношений, для которых снимки состояния
**полны** на обоих концах перехода. При частичном наблюдении нет основания
выводить удаление факта из его отсутствия; такой случай пока отвергается.

Из датированных учебных эпизодов модель извлекает добавления и удаления
фактов. Меняющиеся идентификаторы копируются из ролей события, тип отношения
может прийти из данных. Необъяснимое изменение, неоднозначная роль и новое
событие приводят к отказу. Внутри каждой сигнатуры каждого семейства учтён
не более чем один голос; противоречащие исходы внутри семейства гасят этот
голос. Порог по умолчанию — два независимых семейства, равенство ведущих
эффектов означает отказ. Доля поддержавших семей не объявляется
вероятностью.

Для `development` параметры заморожены, пересечение групп с обучением
запрещено. В `future_stream` прогноз записывается прежде доступа к позднему
исходу; обновление разрешается лишь после сравнения с ним. После начала
будущего потока возвращение к development или дообучение train запрещено.
Прогноз с отсечением раньше уже использованного учебного исхода запрещён.
`sealed_test` не поддерживается этим открытым оценщиком.

Оценщик возвращает отдельно: (а) точность текущего факта **только если**
переданы независимо размеченный эталон и отдельное предсказание факта;
без них результат `None`; (б) точность прогнозируемого состояния и долю
принятых прогнозов; (в) два контроля на одинаковом входе — сохранение
предыдущего состояния и наиболее частый эффект события. Все доли сведены
сначала внутри семейства, затем по семействам поровну; количество эпизодов
остаётся описательным и не выдается за независимые испытания.

| Мера | Числитель | Знаменатель | Отказы |
|---|---|---|---|
| Проверенный текущий факт | Сумма долей точных сравнений `fact_prediction = fact_gold` внутри каждого семейства, где обе независимые разметки предоставлены | Число семейств с проверяемым фактом | При отсутствии пары меток значение не определено; прогноз будущего здесь не учитывается |
| Покрытие будущего | Сумма долей принятых прогнозов внутри каждого семейства | Число семейств с наблюдённым исходом | Отказ снижает долю; не удаляется из знаменателя |
| Точный будущий исход | Сумма долей полных совпадений прогноза со снимком `after` внутри каждого семейства | Число семейств с наблюдённым исходом | Отказ считается отсутствием совпадения |
| Точность среди принятых | Сумма долей совпадений только среди принятых прогнозов каждого семейства | Число семейств хотя бы с одним принятым прогнозом | Если принятых прогнозов нет, значение не определено; покрытие показывается рядом |

Отчёт сохраняет сумму семейных долей и её знаменатель, а также отдельно число
эпизодов, принятых/отклонённых прогнозов и полных совпадений. Эти счётчики
эпизодов служат диагностикой; повтор одной семьи не увеличивает число
независимых единиц.

## Что проверено

Семь профильных тестов на **вымышленных** записях проверяют перенос роли на
новую задачу, отказ от неизвестного события, отсутствие искусственной
уверенности от повторов одной истории, раздельный учёт текущего факта и
прогноза, разбиение по группам и времени. Guarded outcome в тесте вызывает
ошибку, если оценщик читает исход раньше вызова `predict`; spy фиксирует
порядок `predict → learn`. Для временного потока с тремя разными вымышленными
семьями первые два прогноза отклонены и лишь третий поддержан после двух
наблюдённых исходов: покрытие 1/3; это **контроль порядка**, не измерение
качества процесса. Профильные тесты 7/7, Ruff и Pyright прошли локально.

## Ограничения до реальной P13

- Нет обучаемого извлечения события и статуса из русского текста: модуль
  принимает готовые роли и факты, не подтверждает их истинность и права.
- Нет реального task log, владельца, независимых поправок, типизированных
  источников и доступа к ним. Временные метки передаются извне; само
  происхождение данных это API не удостоверяет.
- Механизм учится лишь изменениям в объявленной полностью наблюдаемой области;
  неполные наблюдения P09 требуют отдельной модели скрытого состояния.
- Нет оценки калибровки на реальных семьях, доверительного интервала,
  порогов пилота и свежего закрытого русского набора. Контроли технически
  определены, но их сравнительная эффективность на процессе неизвестна.
- Основания P12 оцениваются отдельно. Наличие другого модуля provenance
  не доказывает, что оно улучшает выбор прогноза P13.
