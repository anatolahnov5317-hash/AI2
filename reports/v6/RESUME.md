## Реализация и важные контракты

- `world.py`/`revision.py`: неизменяемые исходные события + отдельные версии,
  stable IDs, historical `at_turn`, атомарный prepare/commit, хронологический
  replay no-op/связанных эффектов, undo, полные before/after proof архива.
- `dependent_reparse.py`: два ограниченных повторных разбора местоимений по
  реальным старым словам и новым версиям предшествующих смыслов; trace и deps
  проверяются загрузчиком. Потеря нужного источника останавливает транзакцию.
- `uncertainty.py`: conservative lexical guard известного явно названного
  предмета; происхождение и снятие отметок в ограниченном журнале.
- `session.py`: общая фиксация мира, архива, guards, контекста и ответа;
  финальная проверка digest/memory версии; заметки об исправлении/неактуальности
  — фиксированные проверяемые уведомления, не заново обученная речь.
- Реальный hard-exit/restart тест: `tests/test_revision_crash.py`.

## Следующие конкретные вопросы

1. L07: нераспознанное «Они всё перетасовали» не имеет определимого предмета;
   следующие ответы без оговорок используют старые факты. Нужна продуманная
   область неопределённости без выдумывания конкретного объекта.
2. L10: естественные «первый/второй ключ» не имеют поддержанного instance
   binding. Разные явные ID в API уже различаются; это не закрывает язык.
3. Политика/генератор пока прежние; обучение на полном состоянии гипотез не
   выполнено. Шаблонные provenance-уведомления раскрыты в отчёте.
4. Agreement/EvidenceLedger пока не меняют `constrained_choice`; нулевая разница
   абляций честно сохранена. Не объявлять доказанный языковой выигрыш.
5. Два контроля исправления ранее ошибочного ответа оказались неприменимыми
   на новых историях, поскольку исходный выбор был верен. Нужны новые
   независимые композиции для измерения этого качества.

```bash
git fetch origin implementation/v06-block3-revision
git switch -c next-v6-work FETCH_HEAD
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 scripts/run_test_batches.py --output /tmp/ai2-v6-next test_history_revision test_dependent_reparse test_local_uncertainty test_revision_session test_revision_crash
PYTHONPATH=src OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python3 scripts/evaluate_block3.py --output /tmp/ai2-v6-regression.json
```

Полные исходные трассы упакованы стандартным XZ; `lzma` в Python читает их
без дополнительных пакетов. Время ответов исключается только при сравнении
восстановленного выполнения с непрерывным, остальные поля сравниваются целиком.
